# TeraBox no Diniz IPTV v1.2

O Player aceita links HTTP/HTTPS de compartilhamento do TeraBox e abre o player web oficial em tela cheia na TV Box.

Exemplo suportado:

https://www.terabox.com/s/1xxxxxxxx

O modo sem credenciais usa a página oficial de compartilhamento do TeraBox dentro de um WebView dedicado. Links protegidos por senha ou que exijam login seguem as regras do próprio TeraBox.

A Open Platform do TeraBox também possui API oficial de streaming M3U8, mas exige credenciais de aplicativo e token emitidos pelo TeraBox. Essa API não é simulada nem contornada pelo aplicativo.
